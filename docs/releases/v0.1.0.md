# Q-Reliability Lab v0.1.0

`v0.1.0` is the first reproducible release of this focused simulation artifact.

- Exact density-matrix sweep for a Bell state under a first-qubit phase-flip channel.
- Analytic regression tests for Z-basis success, X-basis correlated success,
  fidelity, and coherence.
- Pre-registered seeded finite-shot binomial sweep with 95% Wilson confidence
  intervals.
- Generated CSV data, figures, LaTeX report, and CI checks that regenerate the
  committed scientific artifacts.

This release is a classical simulation benchmark, not quantum-hardware data.
